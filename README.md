# ERIEsistible Clowns website

Static site for the ERIEsistible Clowns of Erie, PA. Hosted on Hostinger, deployed from this GitHub repo.

## What's here

| Path | What it is |
| --- | --- |
| `*.html` | The pages. Generated by `_src/build.py`; edit the build script, not these files. |
| `assets/` | CSS, JS, logo, flyers, share images (`og-*.jpg`). |
| `_src/build.py` | Page template, meta tags and site settings (phone, domain, prices). |
| `_src/events-template.csv` | Starter sheet for the events calendar. |
| `content/events.json` | Fallback events list, used only until the Google Sheet is connected. |

## Before launch

Open `_src/build.py` and fill in the `SITE` settings marked TODO, then run `python3 _src/build.py`:

- `url`: the live domain (used for canonical URLs, Facebook/Google share images and the sitemap)
- `phone`, `hall_price`

## Deploy on Hostinger (manual upload)

Upload everything except `_src/`, `README.md` and `.git` into `public_html` with hPanel's File Manager. The easiest way: upload `erieclowns-upload.zip` (built from this repo) and use File Manager's **Extract**. Re-upload only the files that changed after an edit. Turn on SSL in hPanel, then uncomment the HTTPS redirect in `.htaccess`.

## Events calendar (Google Sheet)

The clowns manage events in a Google Sheet. The events page and the homepage read it live, so no upload or deploy is needed when events change. New edits appear within about 5 minutes (Google's publish delay).

One-time setup:

1. In Google Sheets: File → Import → Upload `_src/events-template.csv` → Replace spreadsheet. Name the tab `Events`.
2. File → Share → **Publish to web** → choose the `Events` tab and **Comma-separated values (.csv)** → Publish. Copy the link.
3. Paste that link into `EVENTS_SHEET_CSV` at the top of `assets/js/site.js` and re-upload that one file.
4. Share the Sheet (Editor access) with whichever clowns will post events.

Columns: **Title**, **Date** (e.g. 11/28/2026), Start time (e.g. 10:00 AM), End time, Type (Parade, Community event, Fundraiser, Clown College, Hall event, Hospital visit), Location, Address, Description, Image URL, Link. Only Title and Date are required. Past events move to the "Past events" list automatically. Image URL can be a public Google Drive share link, an Imgur link, or any direct image link; the photo shows on the right side of the event card. For Imgur albums or galleries, open the picture, right-click it and use **Copy image address**. A link that doesn't load is hidden automatically.

## Request form

Requests are emailed to TheClownRusty@gmail.com through FormSubmit (`FORM_ENDPOINT` in `assets/js/site.js`). The first real submission sends an activation email to that inbox; click the link once and requests start arriving.

## Share previews

Each page has its own title, description, canonical URL, Open Graph and Twitter tags, plus schema.org data (organization, Kury Hall venue, and events from the Sheet). After launch, check pages with the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and submit `sitemap.xml` in Google Search Console.
