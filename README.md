# ERIEsistible Clowns website

Static site for the ERIEsistible Clowns of Erie, PA. Hosted on Hostinger, deployed from this GitHub repo.

## What's here

| Path | What it is |
| --- | --- |
| `*.html` | The pages. Generated by `_src/build.py`; edit the build script, not these files. |
| `assets/` | CSS, JS, logo, flyers, share images (`og-*.jpg`). |
| `content/events.json` | The events calendar. Edited through `/admin`. |
| `admin/` | Decap CMS (event editor) and its GitHub login (`admin/oauth/*.php`). |
| `_src/build.py` | Page template, meta tags and site settings (phone, domain, prices). |

## Before launch

Open `_src/build.py` and fill in the `SITE` settings marked TODO, then run `python3 _src/build.py`:

- `url`: the live domain (used for canonical URLs, Facebook/Google share images and the sitemap)
- `phone`, `hall_price`, `erie_gives` (their own Erie Gives page link)

Also set the repo and domain in `admin/config.yml`.

## Deploy on Hostinger

1. hPanel → Websites → Advanced → **Git**. Repository: this repo's URL, branch `main`, directory left blank (deploys to `public_html`).
2. For a private repo, copy the SSH key Hostinger shows into GitHub → repo Settings → Deploy keys.
3. Turn on **Auto deployment** and add the webhook URL it gives you under GitHub → repo Settings → Webhooks.
4. Turn on SSL in hPanel, then uncomment the HTTPS redirect in `.htaccess`.

## Event editor (Decap CMS)

The clowns add events at `https://<domain>/admin`. Saving commits `content/events.json` to GitHub, the webhook redeploys, and the events page updates in about a minute. No database or server app is needed; the only server code is the two small PHP files that handle the GitHub login.

One-time setup:

1. GitHub → Settings → Developer settings → **OAuth Apps** → New OAuth App.
   - Homepage URL: `https://<domain>`
   - Authorization callback URL: `https://<domain>/admin/oauth/callback.php`
2. In Hostinger's File Manager, copy `public_html/admin/oauth/config.sample.php` to `config.php` in the same folder and paste in the Client ID and a new Client Secret. This file is gitignored and stays on the server only.
3. Each person who edits events needs a free GitHub account, added as a collaborator on this repo (repo Settings → Collaborators).

## Request form

Requests are emailed to TheClownRusty@gmail.com through FormSubmit (`FORM_ENDPOINT` in `assets/js/site.js`). The first real submission sends an activation email to that inbox; click the link once and requests start arriving.

## Share previews

Each page has its own title, description, canonical URL, Open Graph and Twitter tags, plus schema.org data (organization, Kury Hall venue, and events added from the calendar). After launch, check pages with the [Facebook Sharing Debugger](https://developers.facebook.com/tools/debug/) and submit `sitemap.xml` in Google Search Console.
